## Documentation

Before you create, rewrite, or review any document in this repository, read
the documentation skill: [.agent/skills/unifabric-docs/SKILL.md](./.agent/skills/unifabric-docs/SKILL.md).
It defines the document types, the template for each type in
[docs/templates/](./docs/templates/), the common constraints, and the English
prose rules. English is the primary language; every document has a Chinese
translation (`<name>.zh.md`).
